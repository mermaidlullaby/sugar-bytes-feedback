# Sugar Bytes — Feedback & Roadmap

This repository is the public place to follow the Sugar Bytes roadmap and review publicly shareable bug reports and feature requests.

Sugar Bytes is a macro-tracking application focused on protein, carbohydrates, fat, and fiber.

## Report a bug

Before opening a new issue, check the existing issues to see whether the problem has already been reported.

When reporting a bug, include as much of the following as you can:

- **What happened:** Describe the problem clearly.
- **Steps to reproduce:** List the actions that led to it.
- **Expected behaviour:** Explain what you thought should happen.
- **Actual behaviour:** Explain what happened instead.
- **Environment:** Include your browser, operating system, and device when relevant.
- **Evidence:** Add screenshots or other details if they help explain the problem.

Please keep reports focused on one problem per issue.

## Suggest a feature

Feature suggestions are welcome. Explain:

- The problem or need you are trying to address.
- How you would expect the feature to work.
- Why it would be useful.

A proposed feature is not a commitment to implement it. Priorities and plans can change.

## Following progress

Issues are used to track known bugs, enhancements, and roadmap ideas. Their status reflects the current state of that work; an open issue does not necessarily mean that implementation has started or that a delivery date has been set.

This repository contains publicly shareable feedback and roadmap information. It is separate from the private Sugar Bytes application source repository.

## Privacy

Do not post passwords, authentication tokens, private account details, or other sensitive personal information. If a report requires sharing private information, leave it out of the public issue and use an appropriate private contact channel instead.
